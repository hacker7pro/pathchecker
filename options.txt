================================================================
  ToS FIELD BIT STRUCTURE (8 bits)
  [ DSCP - 6 bits ] [ ECN - 2 bits ]

  DSCP = Differentiated Services Code Point
  ECN  = Explicit Congestion Notification
         00 = ECN not supported
         01 = ECN capable (ECT1)
         10 = ECN capable (ECT0)
         11 = Congestion Experienced (CE)

================================================================
  QUICK REFERENCE — Priority Order (Low to High)
  முன்னுரிமை வரிசை (குறைவு முதல் அதிகம் வரை)
================================================================

  CS1  (8)  < Default (0) < CS2 (16) < CS3 (24) <
  AF1x (10-14) < AF2x (18-22) < AF3x (26-30) < AF4x (34-38) <
  CS4 (32) < CS5 (40) < CS6 (48) < CS7 (56) < EF (46)*

  * EF (46) is treated as highest-priority user traffic class.
    CS6/CS7 are reserved for network infrastructure only.
